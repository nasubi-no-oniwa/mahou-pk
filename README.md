# 魔法の球 PK

線を描けば、それが魔球になる。「魔法の球」のPK版。

- キッカー：ボールからゴールまで好きな線を描いて、魔球として登録する（球速は40〜150km/hで自由に決められる）
- キーパー：合言葉で魔球を呼び出し、ボールが来ると思う所をタップして飛びつく。3本のうち1本でも止めれば勝ち
- 止められていない魔球のランキング（今日・全期間）
